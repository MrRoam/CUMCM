# 问题1：交会定位区域的直径与直径圆覆盖

## 1. 第一问究竟要求什么

题面第1页“问题1”要求：给定同一干扰源的若干检测点坐标和示向度，给出交会定位多边形直径算法，并回答直径与该区域直径相同的圆能否覆盖整个区域。角度方向、±1°误差和交会定位定义见题面第2页附录2第1、3条及图2，仓库派生稿见 [B题.md](B题.md)。

完整解答应交付：

1. 从每次测量构造两个半平面，写出定位区域；
2. 给出有效边界与有序顶点算法，说明正确性、复杂度和异常情况；
3. 从顶点计算直径及一对直径端点；
4. 回答“不一定覆盖”，给出反例和对任意输入可执行的覆盖判据。

第一问没有附带一组必须代入得到固定数值的观测表，也没有要求使用模拟器或提交正式测试成绩。本文例子均为人工构造，不是官方答案。代码接受任意合法观测列表，输出由输入决定。

本模块采用题面图2的“角误差交会多边形”口径，只交测向半平面。不加入半径1800米圆域、接收距离圆域或5米排除圆；加入它们会变成带圆弧的区域，不再是本文算法处理的纯多边形。后续问使用额外先验时应另行扩展，而不是悄悄改变第一问的计算对象。

## 2. 数学模型

检测点 S_i=(x_i,y_i)，示向度 θ_i∈[0°,360°)，ε=1°。坐标单位为米，正东为x正向，角度逆时针。

令 u_i^-=(cos(θ_i−ε),sin(θ_i−ε))、u_i^+=(cos(θ_i+ε),sin(θ_i+ε))，则位置 X 的闭测向楔域为

\[
W_i=\{X:u_i^-\times(X-S_i)\ge0,\ u_i^+\times(X-S_i)\le0\},
\qquad P=\bigcap_i W_i.
\]

叉积定义为 a×b=a_xb_y−a_yb_x。两个不等式保留检测点朝向目标的前向窄角，不能把无方向的两条直线解释为两个相反扇区。

每个约束写为 a_jx+b_jy≤c_j，共 m=2n 条。误差界是集合约束，不假设误差服从均匀、正态或独立分布，也不通过重复同址测量缩小误差。

## 3. 方法 A：极角排序与双端队列

对于 ax+by≤c，有向边界取 d=(−b,a)，使允许侧在行进方向左侧。按 d 的极角排序；实现用象限与整数叉积比较，不用浮点角度相减判断平行。同向平行约束仅保留最严格的一条。

维护候选半平面双端队列 Q。每加入 H：

1. 若队尾相邻边界的交点不满足 H，删除队尾并重复；
2. 若队首相邻边界的交点不满足 H，删除队首并重复；
3. 处理平行情形并入队；全部处理后检查首尾闭合。

剩余相邻边界交点组成逆时针顶点序列。队列维护的是有序候选边界链，不应把每个处理中间态都解释为完整闭合多边形。凸性与角度排序保证失效边界可以从两端删除；一旦某约束被其他已处理约束隐含，后续继续取交也不会使它重新必要。

每条约束最多入队一次、出队一次，求交及队列操作合计 O(m)，排序 O(m log m)，空间 O(m)。主程序使用 collections.deque，不使用普通数组删除首元素；没有在求解末尾添加“每个顶点检查每条输入边界”的平方级循环。全配对穷举仅存在于独立测试中。

### 3.1 不使用未经证明的大框

本实现先把有理半平面系数清分母并约为整数。设全部整数系数绝对值不超过 M，M≥1。任意两条非平行边界的行列式为非零整数，绝对值至少1；克拉默公式分子绝对值不超过2M²，所以任意有限顶点满足

\[
|x|,|y|\le2M^2.
\]

取辅助框 [−B,B]²，B=2M²+1。这个框可能非常大，但不是经验倍数：它严格包含所有有界交集。任意非空交集离原点最近的点，要么是原点、某条边界的垂足，要么是两条独立边界的交点；垂足坐标也不超过 M²。因此非空交集必与框内部相交。若原交集无界，其无界方向必穿过框边界；若有界，其全部点均在框内部。

由此能区分：无交集→empty；触及框→unbounded；不触框→按面积及端点区分 polygon、segment、point。无界结果不输出人工截断后的顶点，不冒充真实定位范围。辅助边界也不属于官方先验。

### 3.2 精度与复杂度边界

坐标和系数使用 Fraction；测向的 sin/cos 由 Python 标准库 binary64 计算，再转换为精确有理系数。90°整数倍方向使用精确值，避免 sin(π) 非零残差。此后平行、半平面侧别、覆盖和距离平方均精确判断，不用固定 EPS 合并近乎平行但不同的约束。

这保证的是“对已转换有理输入”的精确性，不是理想实数角度的符号精确性；极端临界输入仍受最初三角函数舍入影响。显示用浮点坐标与长度可能有尾数误差；JSON 同时保存有理顶点、精确距离平方及覆盖余量。

O(m log m) 指几何算术操作数量；整数/有理数操作成本还取决于位数，不能据此承诺 Python 任意精度版与浮点版一样快。本版优先解决正确性与可复核性，尚未进行大规模速度基准。

## 4. 直径：旋转卡壳

设 P 的顶点为 V_0,…,V_{h−1}。任意 X、Y∈P 都是顶点凸组合，三角不等式给出

\[
\|X-Y\|\le\max_{i,j}\|V_i-V_j\|,
\quad D^2=\max_{i,j}\|V_i-V_j\|^2.
\]

因此只需找最远顶点对，但正式算法不再枚举全部顶点对。对每条边 V_iV_{i+1}，维护使有向面积

\[
A(i,j)=(V_{i+1}-V_i)\times(V_j-V_i)
\]

最大的对侧顶点 j；只要 A(i,j+1)>A(i,j)，就向前推进 j。比较该边两个端点与 j 的距离；面积并列时同时比较 j+1，覆盖平行支撑边情形。

最远点对必为某方向下两条平行支撑线的对踵点；旋转支撑线时，对侧索引沿凸边界单调前进。这样枚举全部必要的对踵候选，得到 D² 和端点 A、B，复杂度 O(h)。旋转卡壳与后面的覆盖扫描均不增加排序量级，总算术操作复杂度仍为 O(n log n)。

退化线段的直径为端点距；点的直径为0；空集在本接口中不定义直径；无界非空集的直径为无穷大。JSON 对后二者用 null 与说明表示，不输出不合规范的 Infinity。

## 5. 直径圆能否覆盖：不一定，但能直接判定

取任意直径端点 A、B，D=|AB|。如果一个半径 D/2 的闭圆盘同时包含 A、B，圆心必为 C=(A+B)/2：三角不等式达到等号，或用平方距离恒等式即可证明。因此圆心没有额外优化自由度。

圆盘是凸集，包含所有顶点当且仅当包含整个多边形，故充分必要条件为

\[
\boxed{\max_i\left\|V_i-\frac{A+B}{2}\right\|^2\le\frac{D^2}{4}}
\quad\Longleftrightarrow\quad
\boxed{(V_i-A)\cdot(V_i-B)\le0\quad\forall i}.
\]

程序返回圆心、半径、是否覆盖、最大超出量（米²）及一个不在圆内的顶点编号。若失败，这意味着不存在任何直径为 D 的覆盖圆，而不只是某个任意选取的圆心失败。本文不需要计算最小包围圆，也未将这一额外问题混入实现。

### 5.1 符合本题测向结构的反例

令三角形顶点 A=(0,0)、B=(20,0)、C=(10,10√3)，按 A→B→C→A 逆时针排列。对每条边，以其起点向该边反向延长1000米作为检测点，并取示向度为该边方向加1°。三个检测点及示向度的理想值为

| 检测点 | 坐标（米） | 示向度 |
|---|---|---:|
| S₁ | (−1000,0) | 1° |
| S₂ | (520,−500√3) | 121° |
| S₃ | (510,510√3) | 241° |

每个楔域的下边界恰好沿一条三角形边，允许侧朝向三角形内部。对侧顶点相对该边的张角为 arctan(10√3/1010)<2°，所以另外一条楔域边界不切掉三角形。三个楔域交集恰为此等边三角形。

可取三角形重心为真实源；各站到源距离介于5与1500米之间，示向度误差小于1°，故可与题目给定的有效接收半径相容。三角形也位于目标圆域内。

该区域 D=20米。以任一边为直径的圆半径10米，第三顶点到圆心为10√3米，大于10米，不能覆盖。最小覆盖半径为20/√3米，严格大于10米（此处为等边三角形解析结论，不是程序额外求解结果）。

代码按浮点 sin/cos 生成的例子得到 D≈20.000000000000256米、覆盖=false，尾数偏差来自角度/坐标转换，不能当作物理差异。另一人工两站例得到 D≈49.38542582373432米、覆盖=true。
