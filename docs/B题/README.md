# B 题材料索引

本目录保存 B 题官方材料的可检索派生版本、页面渲染图和团队分析。官方原件位于 `inputs/official/B题/`，原件优先级高于本目录中的任何转换稿。

## 官方原件与 Markdown 对照

| 官方原件 | 可检索派生文件 | 内容 |
|---|---|---|
| `inputs/official/B题/B题.pdf` | [`B题.md`](B题.md) | 题面、四问、附录和测试要求 |
| `inputs/official/B题/附件1.docx` | [`附件1.md`](附件1.md) | 模拟器使用说明和计时规则 |
| `inputs/official/B题/附件2.docx` | [`附件2.md`](附件2.md) | HTTP+JSON 接口、响应语义和示例程序 |
| `inputs/official/B题/format2026.doc` | [`format2026.md`](format2026.md) | 2026 年论文格式规范 |

## 团队分析

- [`B题审题与建模思路.md`](B题审题与建模思路.md)：题意拆解、官方条件、当前假设、四问候选建模路径、潜在亮点和验证边界。

## 图片与页面

- `assets/B题_figures/`：从官方题面相应页面渲染得到的图1和图2，用于修复 Markdown 中的示意图引用。
- `assets/B题_pages/`：官方题面4页的完整页面渲染，用于核对公式、表格和版式。

## 当前缺口

- 官方模拟器程序、登录环境、操作视频和《先读下载说明》尚未收入仓库。
- 尚未确定正式编程工具链。
- 尚无问题1—4的正式代码、自动测试、演练结果或正式测试日志。

在补齐模拟器材料前，不得声称接口已经连通或策略已经通过演练；在模型进入 `src/` 并生成可复核结果前，不得将探索结论直接写成论文结果。
