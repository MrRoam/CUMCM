# B 题材料索引

本目录保存 B 题官方材料的可检索派生版本、页面渲染图和团队分析。官方原件位于 `inputs/official/B题/`，原件优先级高于本目录中的任何转换稿。

| 官方原件 | 可检索派生文件 | 内容 |

| `inputs/official/B题/B题.pdf` | [`B题.md`](B题.md) | 题面、四问、附录和测试要求 |

## 团队分析

- [`project_handoff.md`](project_handoff.md)：下一位 Codex 的完整接续入口，记录工作区状态、确认事项、源码与结果、验证边界及后续候选工作。
- [`B题审题与建模思路.md`](B题审题与建模思路.md)：题意拆解、官方条件、当前假设、四问候选建模路径、潜在亮点和验证边界。
- [`问题1_方法A与验证.md`](问题1_方法A与验证.md)：第一问的交付要求、半平面交与旋转卡壳、直径圆覆盖判据、可实现测向反例及代码运行入口。
- [`问题1_三种区域算法效率对比.md`](问题1_三种区域算法效率对比.md)：方法 A、全交点排除和逐次多边形裁剪的复杂度、同口径实测及使用场景。
- [`问题2_两种选点策略比较.md`](问题2_两种选点策略比较.md)：中垂线最大最小交会角与平面最小平均包围圆半径的探索性比较，含布点权重敏感性、消融与加密核验。
- [`第二问随机抽样验证报告`](../../outputs/q2/randomized_comparison.md)：随机干扰源位置、随机检测候选点与随机误差的多种子独立留出验证，由探索脚本自动生成。
- [`第二问面积平均选点包`](../../src/q2/README.md)：当前采用方案的AI接续入口，包含模型配置、正式评价器、坐标变换接口、搜索入口和验证边界。
