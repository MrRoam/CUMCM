## 2. 背景与任务场景

无线电干扰源的定位和清除属于无线电频谱管理任务。题面将定位过程分为初步监测、区域性排查与精准定位三个阶段。前两个阶段已确定干扰源所在的大致区域；本题研究在该区域内进一步定位并清除目标的工作。[题面第 1 页]

传统方式由技术人员携带测向机等手持设备徒步排查。题设公司计划将自动定位清除系统搭载于机器狗，使其能够在危险环境中代替人员执行任务。比赛通过官方模拟器检验机器狗程序，不要求参赛队实际制造机器狗、测向机或激光设备。[题面第 1 页及附录 3—4]

目标所在区域是以原点为圆心、半径 1800 米的二维圆域，正东为 x 轴正向，正北为 y 轴正向。问题 3、4 中，单只机器狗从原点出发，测向机初始频道为 1，依据检测和清除反馈完成任务。[题面第 1—4 页]

## 3. 研究对象与可用信息

| 对象 | 基础定义 |
|---|---|
| 干扰源 | 待定位和清除的无线电信号源；问题 3、4 中共有 10～16 个，具体数量未知 |
| 频道 | 用整数 1～20 表示；各干扰源频道不同且固定，一个频道最多对应一个源 |
| 全向源 | 向周围 360° 辐射信号；问题 3 的全部目标均为全向源 |
| 定向源 | 在自身定向方向两侧各 90°（含边界）辐射信号，其他方向无辐射；问题 4 含全向源和定向源 |
| 测向机 | 停止移动后，对一个指定频道进行检测，返回无信号、距离过近或有误差的示向度 |
| 示向度 | 在检测点处测得的目标方向角；以正东为 0°，逆时针为正，单位为度 |
| 光学设备与激光枪 | 距离指定目标不超过 20 米时，可精确定位并清除；接口将两步合并为清除指令 |
| 模拟器 | 保存案例真值、执行动作和计时，通过 HTTP+JSON 向机器狗程序反馈结果 |

每个源的有效接收半径在 1000～1500 米之间，具体值不会通过接口给出。正常示向度存在 ±1° 误差，同一地点重复检测不会改变该误差。接口不返回场强数值、目标距离或目标真实坐标。[题面附录 1—2；附件 2 §2、§7]

每局真实数量、频道、位置、接收半径，以及问题 4 中的定向方向均不能直接读取。演练结束后可通过界面查看目标总数和两类源数量；正式测试不显示这些案例真值。附件中的示例动作只用于解释协议和计时，不是供求解的数据集或参考策略。[题面附录 3—4；附件 1 §3、§4.6]

## 4. 四问的输入与交付

### 问题 1：交会定位区域的几何量

- 给定：若干检测点的坐标，以及同一个干扰源在这些检测点处的示向度。
- 要求：采用交会定位法，给出多边形定位区域直径的计算算法。直径定义为区域内任意两点间距离的最大值。
- 另需回答：以该区域直径为直径的圆能否覆盖该定位区域，并给出相应论证。
- 输入形式：题面提出一般算法任务，没有提供这问的具体检测坐标、角度数值表。

### 问题 2：第二检测点的选择

- 给定：某全向干扰源在一个检测点处测得的示向度。
- 要求：给出第二检测点的选择策略，以获得较好的定位效果，并给出第二检测点的候选区域。
- 题面没有指定“较好”的唯一数学评价函数或数值阈值；本版不预先选定该口径。

### 问题 3：全向源的完整任务

- 条件：全部干扰源为全向源，共 10～16 个但具体数量未知；机器狗从原点、频道 1 开始。
- 目标：在确保全部源被清除的前提下，尽量缩短任务完成时间。
- 要求：自动搜索、定位和清除的策略与算法；通过演练报告清除比例、平均定位清除时间。
- 正式交付：充分演练后完成三次正式测试，按题面表 1 报告结果，并导出三份正式日志放入支撑材料，保留原文件名。

### 问题 4：混合源的完整任务

- 变化：目标包括全向源和定向源；仍为 10～16 个，定向源数量及定向方向未知。
- 其他条件：与问题 3 相同。
- 要求：该条件下的检测清除策略与算法、演练有效性检验，以及本问另外三次正式测试结果和对应日志。

以上任务依据题面第 1—2 页和附录 3—4。详细交付字段及计时口径见 [problem_contract.md](problem_contract.md)。

## 5. 各问关系与项目边界

问题 1 研究给定观测下的定位区域；问题 2 研究获取下一次观测的位置；问题 3 将检测、移动、清除组织为完整任务；问题 4 更改信号辐射条件后提出同类完整任务要求。它们在对象和设备规则上相通，但本版不指定跨问复用的具体算法，也不把题号顺序规定为实际开发顺序。

本项目需要交付数学模型说明、算法、可运行的机器狗程序、演练统计、正式测试结果与日志，以及符合竞赛要求的论文和支撑材料。原始题目及附件只读，正式代码与结果按仓库 [AGENTS.md](../AGENTS.md) 管理。

本版尚未确定编程工具链、论文主格式、团队分工、数学模型、参数及评价补充口径。已有 Python 环境检查文件不代表最终语言或正式算法已经选定。
