## 要完成的内容

- 从一个检测点及其示向度出发，明确目标的可能位置与未知接收半径。
- 定义并说明“较好的定位效果”的评价标准。
- 给出第二检测点的候选区域和可执行的选择策略，说明接收可靠性、交会效果及移动代价。
- 形成可运行代码、代表性算例、必要边界验证及图表，说明两次检测的能力边界。
- 明确哪些候选点与评价结果可供第三问使用，保留第三问根据全局任务重新选择的自由。
